# write-prd

**Type:** skill · installs to `~/.claude/skills/write-prd/`

Interviews you at the start of a greenfield project or a major/minor feature to uncover the
underlying need, then writes a Product Requirements Document (`docs/prd/NNNN-slug.md`) covering
problem, users, goals, non-goals, and open questions. Hands off to plan-first work (the
`~/.claude/CLAUDE.md` working method) once the PRD is approved.

Auto-invoked when the request looks like starting something new ("start a new project", "write
a PRD", "I want to build X"), or run explicitly with `/write-prd`.
