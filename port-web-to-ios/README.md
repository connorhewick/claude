# port-web-to-ios

**Type:** skill · installs to `~/.claude/skills/port-web-to-ios/`

Ports a web app to an equivalent iOS experience — from a `package.json`-rooted web project
(React/Vue/Svelte/Angular/vanilla) for a high-fidelity port, or from screenshots/a live URL/a
Figma export for a visual-approximation port. Inventories routes, components, styling, state,
and data flow; interviews on the native-vs-hybrid decision, iOS UI framework, and fidelity
trade-offs; produces a port plan; then scaffolds the Xcode project and drives the port
screen-by-screen.

Auto-invoked for requests like "port this web app to iOS" or "convert this React app to
SwiftUI". Not for greenfield iOS work with no web reference, or one-off UI snippet conversions.
