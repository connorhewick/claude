# port-ios-to-web

**Type:** skill · installs to `~/.claude/skills/port-ios-to-web/`

Ports an iOS app to an equivalent web experience — from SwiftUI/UIKit source for a high-fidelity
port, or from screenshots/App Store images/screen recordings for a visual-approximation port.
Inventories screens, navigation, components, styling, state, and data flow; interviews on stack
and fidelity trade-offs; produces a port plan; then scaffolds the web app and drives the port
screen-by-screen.

Auto-invoked for requests like "port this iOS app to the web" or "build a web version of my
iPhone app". Not for greenfield web work with no iOS reference, or one-off UI snippet
conversions.
